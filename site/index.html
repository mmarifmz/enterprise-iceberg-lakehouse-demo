Enterprise Iceberg Lakehouse

An end-to-end data engineering showcase: Microsoft AdventureWorks enters through Airflow and PySpark, lands as Apache Iceberg on S3-compatible storage, and becomes queryable through Trino.

OrchestrationApache Airflow with external managed PostgreSQL metadata.
ComputeSpark and PySpark ingestion running on Kubernetes.
Open storageIceberg tables and Parquet files on MinIO/S3.
SQL analyticsTrino queries the same open tables without copying data.
AdventureWorks → Airflow → Spark → Iceberg REST → MinIO/S3 → Trino
Runs locally on kind and can be recreated on a short-lived DigitalOcean k3s Droplet.
